# 绿野巡游：贪吃蛇

一个零依赖的网页版贪吃蛇小游戏，支持电脑键盘和手机触控。

## 运行

直接用现代浏览器打开 `index.html` 即可游玩。也可以在项目目录启动任意静态文件服务器，再访问它提供的页面地址。

## 操作

| 操作 | 按键 / 手势 |
| --- | --- |
| 控制方向 | 方向键或 `W` `A` `S` `D`；手机上滑动棋盘或点击方向按钮 |
| 开始 / 暂停 / 继续 | `空格`，或点击页面按钮 |
| 重新开始 | `R`，或点击「重新开始」 |

吃到果实得 1 分；每得 5 分升一级，移动速度随之提升。撞到边界或自己的身体时游戏结束。最高分保存在当前浏览器的本地存储中。

## 项目文件

- `index.html`：页面结构与操作界面
- `style.css`：布局、配色和响应式样式
- `script.js`：游戏规则、绘制、输入与分数记录

无需安装依赖或执行构建命令。
